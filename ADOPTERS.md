# Adopters

This page lists organizations that have said in public that they run the MCP Gateway & Registry in production. Other teams can see what the project is used for, and the maintainers learn which deployment modes and features people depend on.

Adding your organization takes about five minutes.

## How to Add Your Organization

You can add your organization in either of two ways:

- [Edit this file](https://github.com/agentic-community/mcp-gateway-registry/edit/main/ADOPTERS.md) on GitHub, which opens a pull request for you.
- [Open a pull request](https://github.com/agentic-community/mcp-gateway-registry/pulls) from your fork, as described in the [Contributing Guide](CONTRIBUTING.md).

Add one row to the bottom of the table and use this commit title:

```
docs: add <ORGANIZATION_NAME> to ADOPTERS.md
```

Only add an organization you are allowed to name in public. The person in the Contact column should be someone the maintainers can reach on GitHub with questions about the entry.

If you need help, ask in [GitHub Discussions](https://github.com/agentic-community/mcp-gateway-registry/discussions).
